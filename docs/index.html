Features

From first photo to training data

Everything you need to collect a clean image classification dataset, without a laptop or a cloud account.

Capture fast

Tap for one image, or hold the shutter to record about five frames a second. Pick from the photo library too.

Auto-sort with on-device AI

Shoot without choosing a class. A MobileNetV3 model saves each image to the class it looks most like.

Class balance

See counts per class and get warned about empty, small or imbalanced classes before you train.

Import anything

Add a folder to a class, or import a folder or zip of class folders. Nested splits like train/val are detected.

Review and fix

Browse each class, view images full screen, and multi-select to move or delete mislabelled shots.

Image settings

Keep originals, or resize to fit or square and convert to JPEG, PNG or WebP, per app or per dataset.

Auto-sort

Point, shoot, and it lands in the right class

DataDroid learns your classes from the images you already have, then sorts new ones as you capture. No training step, no upload.

  1. Embed

    An on-device MobileNetV3-Small model turns each image into a 1,024-number embedding. Embeddings are cached, so each image is analysed once.

  2. Match

    Each new image is compared with every class and saved to the most similar one.

  3. Catch the unknown

    Images unlike every class wait under Unknown, where one tap starts a new class with them.

"Unknown detection" sets how alike an image must be to join a class. Set it to 0 to always use the closest class.

Export

A zip your training code already understands

One folder per class plus a small metadata.json, shared through the system share sheet.

  • Works with folder-based loaders such as PyTorch ImageFolder and Keras image_dataset_from_directory
  • Empty classes are left out
  • Import the same zip back as a new dataset on either platform

Built with Kotlin Multiplatform

About 85% shared Kotlin

UI, view models, storage, zip handling and the sorting logic are written once in commonMain. Only the camera, image codecs, pickers, the share sheet and the model runtime are platform code.

85% common

  • iosMain · ~760 lines

Get started

Run it yourself

Clone the repository, then build for the platform you want. The README has the full requirements.

Android

  1. Open the project in Android Studio, or use the command line.
  2. Connect a device or start an emulator (Android 7.0+).
  3. Install the debug build:
git clone https://github.com/tawhidmonowar/DataDroid.git
cd DataDroid && ./gradlew :androidApp:installDebug

iOS

  1. Open iosApp/iosApp.xcodeproj in Xcode on a Mac.
  2. Pick the iosApp scheme and an iOS 18.2+ simulator.
  3. Press Run. The first build compiles the shared Kotlin code and downloads TensorFlow Lite.

For a real device, which you need for the camera, set TEAM_ID in iosApp/Configuration/Config.xcconfig.
