# Screenshots

Drop PNG screenshots here with these exact names. The site shows a placeholder for any file that is missing,
so you can add them one at a time.

| File | Shown in | What to capture |
|---|---|---|
| `datasets.png` | Hero, gallery | Home screen with a few datasets |
| `auto-sort.png` | Hero, gallery | Auto-sort camera with the live class match |
| `dataset.png` | Gallery | A dataset with classes and image samples |
| `balance.png` | Gallery | Class balance card with bars and a warning |
| `settings.png` | Gallery | Image settings (size and format) |

Use portrait phone screenshots, roughly 9:19.5 (for example 1080 × 2340). Other sizes work but are cropped to
fill the phone frame. Keep each file under about 500 KB; PNG from a screenshot is fine, or convert to WebP and
update the `src` in `index.html`.
